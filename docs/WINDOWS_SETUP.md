# Windows PC에서 프로그램 켜기 (처음 한 번만 따라 하세요)

코딩을 몰라도 됩니다. 아래 순서대로 **클릭만** 하면 됩니다.

---

## 1. Node.js 설치 (처음 한 번만)

Node.js는 이 프로그램을 PC에서 돌려 주는 무료 도구입니다.

1. 인터넷 브라우저에서 **https://nodejs.org/ko/download** 접속
2. 화면에서 **"Windows 설치 프로그램 (.msi)"** 를 눌러 내려받기
   - 버전은 **LTS**(장기 지원)라고 적힌 것을 고르세요.
3. 내려받은 파일을 더블클릭
4. 설치 창에서 계속 **Next(다음)** 만 누르고, 마지막에 **Install(설치)** → **Finish(마침)**
   - 중간에 "Tools for Native Modules" 체크 상자가 나오면 **체크하지 않은 채로** 넘어가세요.

---

## 2. 프로그램 파일 내려받기

1. GitHub에 로그인된 브라우저에서 아래 주소를 엽니다. (누르면 ZIP 파일이 바로 내려받아집니다)

   https://github.com/cth7045-cloud/baduk-lesson/archive/refs/heads/claude/baduk-tutoring-web-u8zoia.zip

2. 내려받은 ZIP 파일을 마우스 **오른쪽 클릭 → "압축 풀기"(또는 "모두 압축 풀기")**
3. 압축이 풀린 폴더를 찾기 쉬운 곳(예: `문서` 폴더)으로 옮겨 두세요.
   - 폴더 이름은 `baduk-lesson-claude-baduk-tutoring-web-u8zoia` 처럼 길게 나오는데, 원하면 `바둑수업` 처럼 바꿔도 됩니다.

> 새 버전이 나오면 이 2번만 다시 하면 됩니다. (옛 폴더는 지워도 됩니다. 연습판 내용은 브라우저에 저장되어 있어 그대로 남습니다.)

---

## 3. 바탕화면에 실행 아이콘 만들기 (처음 한 번만)

1. 압축을 푼 폴더 안의 **`windows`** 폴더를 엽니다.
2. **`바탕화면-바로가기-만들기.bat`** 을 더블클릭
   - 파란 창으로 **"Windows의 PC 보호"** 가 뜨면 → **"추가 정보"** 클릭 → **"실행"** 클릭
     (인터넷에서 받은 파일이라 Windows가 한 번 확인하는 것입니다.)
3. 검은 창에 "바탕화면에 '바둑 수업 시작' 아이콘을 만들었습니다." 가 나오면 아무 키나 눌러 창을 닫습니다.

이제 바탕화면에 **바둑돌 모양의 "바둑 수업 시작"** 아이콘이 생깁니다.

---

## 3-1. 서버 연결 정보 넣기 (처음 한 번만)

[SUPABASE_SETUP.md](SUPABASE_SETUP.md)의 3번을 따라 `windows/서버-연결-설정.bat` 을 실행하세요.
(하지 않으면 "바둑 수업 시작"을 처음 눌렀을 때 같은 창이 자동으로 뜹니다.)

---

## 4. 프로그램 켜기 (매번)

1. 바탕화면의 **"바둑 수업 시작"** 아이콘을 더블클릭
2. 검은 창이 뜨고 잠시 기다리면 브라우저에 바둑판이 열립니다.
   - **처음 한 번은 1~3분** 정도 걸립니다. (필요한 파일을 내려받는 중)
   - **"Windows 보안 경고 - Node.js"** 창이 뜨면 **"액세스 허용"** 을 누르세요.
     (같은 와이파이의 폰·태블릿에서 접속할 수 있게 해 줍니다.)
3. 다 쓴 뒤에는 **검은 창을 닫으면** 프로그램이 꺼집니다.

### 폰·태블릿에서 같이 시험해 보기
- 폰이 PC와 **같은 와이파이**에 연결되어 있어야 합니다.
- 검은 창에 `Network:  http://192.168.x.x:5173/` 같은 줄이 보이면, 그 주소를 폰의 Chrome이나 삼성 인터넷 주소창에 그대로 입력하세요.
- 이것은 시험용입니다. 실제 수업에서 학생들이 쓰는 주소는 나중에 인터넷에 올리는 단계(배포)에서 만듭니다.

---

## 문제가 생기면
| 증상 | 해결 |
|---|---|
| "Node.js 가 설치되어 있지 않습니다" | 1번을 다시 하고, **PC를 한 번 재시작**한 뒤 다시 실행 |
| 검은 창이 바로 닫힘 | 압축을 풀지 않고 ZIP 안에서 바로 실행한 경우입니다. 2번의 "압축 풀기"를 먼저 하세요 |
| 브라우저가 안 열림 | 브라우저 주소창에 `http://localhost:5173` 입력 |
| 그 밖의 오류 | 검은 창의 내용을 사진으로 찍어 보내 주세요 |
